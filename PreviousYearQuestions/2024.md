#### Detailed Textual Explanation of Circuit Diagram (for Non-Vision LLMs / System Modeling)
- **Circuit Type:** Planar three-mesh DC resistive electric network.
- **Components & Topologies:**
  1. **Mesh 1 (Leftmost Loop):**
     - Contains an independent ideal DC voltage source of $500\text{ V}$ in the left branch with positive terminal at the top and negative terminal at the bottom.
     - Top horizontal branch contains a resistor of $10\ \Omega$.
     - Right vertical branch (shared between Mesh 1 and Mesh 2) contains a resistor of $20\ \Omega$.
     - Bottom horizontal line is an ideal reference/ground conductor.
     - Assigned clockwise mesh current: $I_1$.
  2. **Mesh 2 (Middle Loop):**
     - Left branch (shared with Mesh 1) has the $20\ \Omega$ resistor.
     - Top branch is an ideal connecting wire.
     - Right branch (shared between Mesh 2 and Mesh 3) contains a resistor of $100\ \Omega$.
     - Bottom branch is an ideal connecting wire.
     - Assigned clockwise mesh current: $I_2$.
  3. **Mesh 3 (Rightmost Loop):**
     - Left branch (shared with Mesh 2) has the $100\ \Omega$ resistor.
     - Top branch is an ideal connecting wire.
     - Right vertical branch contains an independent ideal DC current source of $5\text{ A}$ directed downwards.
     - Assigned clockwise mesh current: $I_3$.
- **Governing Equations (Mesh / Loop Analysis):**
  - **From Mesh 3:** Since the outer right branch has only the downward $5\text{ A}$ current source aligned with clockwise mesh current $I_3$:
    $$I_3 = 5\text{ A}$$
  - **From Mesh 1 (KVL):**
    $$-500 + 10 I_1 + 20(I_1 - I_2) = 0 \implies 30 I_1 - 20 I_2 = 500$$
  - **From Mesh 2 (KVL):**
    $$20(I_2 - I_1) + 100(I_2 - I_3) = 0 \implies -20 I_1 + 120 I_2 - 100 I_3 = 0$$
  - **System of Equations to solve via Gauss-Seidel Method:**
    $$\begin{cases} 30 I_1 - 20 I_2 + 0 I_3 = 500 \\ -20 I_1 + 120 I_2 - 100 I_3 = 0 \\ 0 I_1 + 0 I_2 + 1 I_3 = 5 \end{cases}$$
    Or substituting $I_3 = 5\text{ A}$ directly into Mesh 2:
    $$\begin{cases} 30 I_1 - 20 I_2 = 500 \\ -20 I_1 + 120 I_2 = 500 \end{cases}$$
