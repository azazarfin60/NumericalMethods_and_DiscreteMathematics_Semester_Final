# Previous Year Questions

Frozen source files. 8 semester-final papers (2017–2024), 1 class-test file, and the topic-sorted question bank.

**These files are never edited after P0.** Their SHA-256 hashes are stored in `../scripts/source_manifest.sha256` and re-checked at every gate. Any change stops the build.

## Contents

| File | What it holds |
| :-- | :-- |
| `2017.md` – `2024.md` | One paper per year. Verbatim question text with marks and section headers. |
| `ClassTestQuestions.md` | CT-01, CT-02A, CT-02B, CT-04. All four class tests in one file. |
| `topic_wise_sorted_questions.md` | Every sub-question from all papers and CTs sorted by the subtopic taxonomy in `../topic_subtopic_list.md`. |
| `diagrams/` | Figures referenced by the question papers. Cropped from scanned originals. |

## Paper coverage

| Years | Section A | Section B |
| :-- | :-- | :-- |

Discrete Mathematics entered the course in 2022. The 2017–2021 papers are 100% Numerical Methods.
