## How these notes are used

They are **read-only reference material** for the answer build. The `combined_analysis_report.md` in the root cross-references these notes with Raidah's notes, the syllabus, and the exam papers.

No answer file copies text from here. The notes inform which topics were taught and what traps the instructor flagged. The answers are authored independently from the question papers and the textbooks.
