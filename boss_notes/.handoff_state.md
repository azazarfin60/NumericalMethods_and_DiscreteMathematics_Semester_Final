## The three real defects Phase 10 found

The audit's headline result. All three are the same failure: **two years asked the same
question on different data, and the boss note showed only the earlier year's answer.** A
student revising from these notes would have walked into the exam with the wrong numbers.

### 1. 2024 Q.2(b) had no answer anywhere (NM-3.5, NM-3.8)

`scripts/merge_map.csv` classes 2020 Q.4(b) and 2024 Q.2(b) as an **L2 merge**, so both boss
notes folded them into one Golden Question using the 2020 circuit. But the circuits differ:

| | 2020 Q.4(b) | 2024 Q.2(b) |
| :-- | :-- | :-- |
| Source | $400\text{ V}$, $10\text{ A}$ | $500\text{ V}$, $5\text{ A}$ |
| Resistors | $20, 40, 10, 100\ \Omega$ | $10, 20, 100\ \Omega$ |
| Fixed branch | $I_3 = 10\text{ A}$ | $I_3 = 5\text{ A}$ |
| Answer | $I_1 = 13.5135\text{ A}$, $I_2 = 10.2703\text{ A}$ | $I_1 \approx 21.875\text{ A}$, $I_2 \approx 7.8125\text{ A}$ |

L2 merging is correct for the **topicwise** layer, where the point is the method. It is wrong
for a revision note, where the student needs the answer to the question in front of them. NM-3.5
now carries the full 2024 solution with its own circuit figure and the origin boxed result.
NM-3.8 points at NM-3.5 rather than implying the 2020 numbers cover both.

### 2. 2023 Q.4(b) answered with the wrong Simpson variant (NM-5.2)

Same integral in both years, different instruction:

| | 2018 Q.6(a) | 2023 Q.4(b) |
| :-- | :-- | :-- |
| Instruction | "eight-segment Simpson's 1/3" | "Simpson's 1/3 rule", no count |
| Segments | $n = 8$, $h = 2.75$ | $n = 2$, $h = 11$ |
| $x$ | $11061.3548$ m | $11065.72$ m |
| $E_t$ | $-0.0193$ m | $-4.38$ m |
| $\lvert\epsilon_t\rvert$ | $0.00017\%$ | $0.0396\%$ |

The 2023 error is about 227 times larger. NM-5.2 now has both, with the reasoning for why an
unqualified "Simpson's 1/3" means the two-segment rule, and a comparison table.

### 3. 2020 Q.8(b) had the wrong grid (NM-10)

NM-10 merged 2018 Q.8(a) and 2020 Q.8(b) and answered both with the 2018 potentials
($V_1 = 71.875$ V and so on). But 2020 prints a **different grid**: boundary $1$ on top and $0$
on the other three edges, not $100$, $75$, $50$ and $0$ volts. The origin answers it as an
error problem, $E_1 = E_2 = 0.125$ and $E_3 = E_4 = 0.375$, with an exact rational check.
NM-10 now carries that as its own Golden Question, with the real exam figure. Worth 06 marks.

## Six Rule B violations repaired

Gate V5's docstring settles how strict "character-identical" is: *"No other normalisation is
done, so a changed digit still fails"*, and the 2023 Simpson case is cited as the precedent for
rejecting a change that *"renders almost identically"*. All six were in Exam Variants summary
tables, where results had been retyped rather than copied.

Four were bar rewrites, and these were not cosmetic. `\|` is a LaTeX **double** bar, the norm
symbol, so `$\boxed{\|e\|}$` renders as ‖e‖ where the origin renders |e|. A student reading
absolute error as a norm symbol is being taught something wrong.

| File | Was | Origin |
| :-- | :-- | :-- |
| NM-1.5 | `\left\|\frac{du}{u}\right\|` | `\left|\frac{du}{u}\right|` |
| NM-1.5 | `\|e\|` | `\|e\|` → `|e|` |
| NM-1.5 | `\|E_a\|` | `|E_a|` |
| NM-1.6 | `\|E_3\|` | `|E_3|` |
| NM-5.2 | `\frac{h}{3}(f_0+4f_1+f_2)\ \text{exact deg} \le 3` | full origin sentence |
| NM-5.2 | `v_0(1.25) = -106.34\ \text{V}` | `v_0(1.25) = -106.34 \text{ V}` |

Character identity and Markdown table placement are mutually exclusive, because a bare `|` ends
the cell. Those four rows now point to the block that carries the verbatim box rather than
holding a corrupted copy. Duplicating the box below the table was rejected: a third copy of a
number is a new drift risk, and the box already exists verbatim in the same file.
