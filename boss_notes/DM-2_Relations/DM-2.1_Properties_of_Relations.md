# DM-2.1: Properties of Relations

> ⚫ **Never examined.** This note exists for reading flow and complete syllabus coverage. Skim it to connect the ideas, but do not spend heavy study time here.

## What This Is

A relation on a set $A$ is a collection of ordered pairs from $A \times A$. Four classic properties classify how elements relate to each other: reflexivity, symmetry, antisymmetry, and transitivity.

## 📝 Key Definitions

> **Reflexive:** "A relation $R$ on a set $A$ is called reflexive if $(a, a) \in R$ for every element $a \in A$." -- Rosen, §9.1
>
> **In simple words:** Every element is related to itself. On a graph, every node has a self-loop.

> **Symmetric:** "A relation $R$ on a set $A$ is called symmetric if $(b, a) \in R$ whenever $(a, b) \in R$, for all $a, b \in A$." -- Rosen, §9.1
>
> **In simple words:** If $a$ connects to $b$, then $b$ must connect back to $a$. Connections are two-way streets.

> **Antisymmetric:** "A relation $R$ on a set $A$ such that for all $a, b \in A$, if $(a, b) \in R$ and $(b, a) \in R$, then $a = b$ is called antisymmetric." -- Rosen, §9.1
>
> **In simple words:** Two different elements can never point to each other. The only two-way connections allowed are self-loops.

> **Transitive:** "A relation $R$ on a set $A$ is called transitive if whenever $(a, b) \in R$ and $(b, c) \in R$, then $(a, c) \in R$, for all $a, b, c \in A$." -- Rosen, §9.1
>
> **In simple words:** If you can go from $a$ to $b$ and from $b$ to $c$, you can skip straight from $a$ to $c$.

## Key Examples

Equality ($=$) is reflexive, symmetric, and transitive. Inequality ($\le$) and divisibility ($\mid$) are reflexive, antisymmetric, and transitive.
