# Year-wise Exam-style Answers

One file per past paper: `2017_answer.md` through `2024_answer.md`.

Each file answers every sub-question of that paper in the short form an answer
script uses. Working is shown. Nothing is explained at length. For
the long form, see `../answers_explanation/`.

**These are the origin files.** Every number, box and derivation in the
topic-wise folders is copied from here and is never retyped. If a number here is
wrong, it is wrong everywhere, so this is the only place a number is authored.

## Order of work

Papers were answered newest first, `2024` down to `2017`. The two OBE papers come
first because they carry CO tags.

## Rules these files follow

| Rule | What it means |
| :-- | :-- |
| One answer per manifest row | `scripts/answer_manifest.csv` lists all 183 paper sub-questions (plus 19 class-test parts = 202 total rows). Every one gets an answer. |
| Marks come from the paper margin | A 2 mark item is never labelled 3. |
| Every number derived twice | Two independent routes. A disagreement is settled before the next question is written, and the trap is noted in a callout. |
| No invented questions | Nothing appears here that is not in the paper (Rule C). No practice, similar, or bonus drills. |
| LaTeX fences on their own lines | `$$` sits alone. Never glued to content. |
| `diagrams/` is relative | `![Alt](diagrams/name.jpg)` |

## Reading a block

```
### **(b) Find the positive root of f(x) = x^3 - 3x^2 - x - 3 = 0 by secant
method. [Marks: 04]**

f(0) = -3 < 0, f(5) = 47 > 0, so a root lies in (0, 5).
...
$$\boxed{x \approx 3.49}$$
```

No em dashes. No `Furthermore`, `Moreover`, `Consequently`. Plain words.
