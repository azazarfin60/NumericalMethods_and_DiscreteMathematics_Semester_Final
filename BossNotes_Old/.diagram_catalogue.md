## 6. Verification method, for reuse

Provenance in this file is measured, not remembered:

```bash
for f in boss_notes/diagrams/*.jpg; do
  h=$(md5sum "$f" | cut -d' ' -f1)
  find . -path ./boss_notes -prune -o \( -name '*.jpg' -o -name '*.png' \) -print0 \
    | xargs -0 -I{} sh -c '[ "$(md5sum "$1" | cut -d" " -f1)" = "$2" ] && echo "$1"' _ {} "$h" | head -1
done
```

The `-print0` and `-0` are required. The textbook directory names contain spaces
(`Chapter 06 - Counting`), so a plain `find | xargs md5sum` silently truncates every path and
reports the Rosen diagrams as having no source. That bug produced the first draft of this
catalogue, in which four Phase 9 diagrams were wrongly recorded as generated.

To find orphans:

```bash
cd boss_notes
for f in diagrams/*.jpg; do b=$(basename "$f"); grep -qF "$b" *.md || echo "unused: $b"; done
```

As of Phase 10 this prints nothing.
