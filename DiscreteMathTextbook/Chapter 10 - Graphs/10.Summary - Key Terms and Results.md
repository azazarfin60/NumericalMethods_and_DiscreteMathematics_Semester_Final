# Chapter 10 — Key Terms and Results

## Key Terms

### Section 10.1: Graphs and Graph Models
*See [[10.1 Graphs and Graph Models]]*

- **undirected edge:** an edge associated with an unordered pair $\{u, v\}$ of vertices.
- **directed edge:** an edge associated with an ordered pair $(u, v)$ of vertices, directed from initial vertex $u$ to terminal vertex $v$.
- **multiple edges (parallel edges):** distinct edges that connect the same pair of vertices.
- **multiple directed edges:** distinct directed edges associated with the same ordered pair $(u, v)$.
- **loop:** an edge connecting a vertex to itself.
- **undirected graph:** a pair $G = (V, E)$ consisting of a nonempty set $V$ of vertices and a set $E$ of undirected edges.
- **simple graph:** an undirected graph with no multiple edges and no loops.
- **multigraph:** an undirected graph that may contain multiple edges connecting the same pair of vertices, but no loops.
- **pseudograph:** an undirected graph that may contain both multiple edges and loops.
- **directed graph (digraph):** a pair $G = (V, E)$ consisting of a nonempty set $V$ of vertices and a set $E$ of directed edges.
- **simple directed graph:** a directed graph with no loops and no multiple directed edges.
- **directed multigraph:** a directed graph that may contain multiple directed edges between the same ordered pair of vertices.
- **mixed graph:** a graph containing both directed and undirected edges.

### Section 10.2: Graph Terminology and Special Types of Graphs
*See [[10.2 Graph Terminology and Special Types of Graphs]]*

- **adjacent (neighbors):** two vertices $u$ and $v$ are adjacent if they are connected by an edge.
- **incident:** an edge is incident with a vertex if that vertex is an endpoint of the edge.
- **neighborhood $N(v)$:** the set of all vertices adjacent to $v$.
- **degree of a vertex $\deg(v)$:** the number of edges incident with $v$, with each loop contributing $2$.
- **isolated vertex:** a vertex of degree $0$.
- **pendant vertex:** a vertex of degree $1$.
- **in-degree $\deg^-(v)$:** the number of directed edges with $v$ as their terminal vertex.
- **out-degree $\deg^+(v)$:** the number of directed edges with $v$ as their initial vertex.
- **underlying undirected graph:** the undirected graph obtained by replacing all directed edges with undirected edges.
- **complete graph $K_n$:** a simple graph containing an edge between every pair of its $n$ vertices.
- **cycle $C_n$ ($n \ge 3$):** a graph with $n$ vertices $v_1, v_2, \dots, v_n$ and edges $\{v_1, v_2\}, \{v_2, v_3\}, \dots, \{v_{n-1}, v_n\}, \{v_n, v_1\}$.
- **wheel $W_n$ ($n \ge 3$):** the graph obtained by adding a hub vertex to $C_n$ connected to all $n$ cycle vertices.
- **$n$-cube $Q_n$ ($n \ge 1$):** the graph whose vertices are the $2^n$ bit strings of length $n$, with edges between bit strings differing in exactly one bit.
- **bipartite graph:** a graph whose vertex set can be partitioned into two disjoint sets $V_1$ and $V_2$ such that every edge connects a vertex in $V_1$ to a vertex in $V_2$.
- **complete bipartite graph $K_{m,n}$:** a bipartite graph with partition sizes $m$ and $n$, having an edge between every vertex of $V_1$ and every vertex of $V_2$.
- **matching:** a set of edges without common endpoints.
- **maximum matching:** a matching containing the largest possible number of edges.
- **complete matching from $V_1$ to $V_2$:** a matching where every vertex in $V_1$ is an endpoint of a matched edge.
- **regular graph ($k$-regular):** a graph where every vertex has the same degree $k$.
- **subgraph of $G = (V, E)$:** a graph $(W, F)$ where $W \subseteq V$ and $F \subseteq E$.
- **induced subgraph $G[A]$:** the subgraph whose vertex set is $A \subseteq V$ and whose edge set consists of all edges of $G$ with both endpoints in $A$.
- **union of graphs $G_1 \cup G_2$:** $(V_1 \cup V_2, E_1 \cup E_2)$.

### Section 10.3: Representing Graphs and Graph Isomorphism
*See [[10.3 Representing Graphs and Graph Isomorphism]]*

- **adjacency list:** a table specifying the vertices adjacent to each vertex of the graph.
- **adjacency matrix:** an $n \times n$ matrix $A = [a_{ij}]$ where $a_{ij}$ represents the number of edges connecting vertex $v_i$ to vertex $v_j$.
- **incidence matrix:** an $n \times m$ matrix $M = [m_{ij}]$ representing which vertices $v_i$ are incident with edges $e_j$.
- **graph isomorphism:** an adjacency-preserving bijection $f: V_1 \to V_2$ between simple graphs $G_1 = (V_1, E_1)$ and $G_2 = (V_2, E_2)$.
- **isomorphic invariant:** a property that isomorphic graphs must share (e.g., number of vertices, number of edges, degree sequence, presence of cycles of length $k$).

### Section 10.4: Connectivity
*See [[10.4 Connectivity]]*

- **path:** a sequence of edges connecting a sequence of vertices from start to finish.
- **simple path:** a path that does not contain any edge more than once.
- **circuit (cycle):** a path of length $\ge 1$ that begins and ends at the same vertex.
- **simple circuit:** a circuit that does not contain any edge more than once.
- **connected graph:** an undirected graph with a path between every pair of distinct vertices.
- **connected component:** a maximal connected subgraph of an undirected graph.
- **cut vertex (articulation point):** a vertex whose removal increases the number of connected components.
- **cut edge (bridge):** an edge whose removal increases the number of connected components.
- **nonseparable graph:** a connected graph without cut vertices.
- **vertex cut:** a subset of vertices whose removal disconnects the graph.
- **vertex connectivity $\kappa(G)$:** the minimum number of vertices whose removal disconnects $G$ or reduces it to a single vertex.
- **$k$-connected graph:** a graph with $\kappa(G) \ge k$.
- **edge cut:** a set of edges whose removal disconnects the graph.
- **edge connectivity $\lambda(G)$:** the minimum number of edges whose removal disconnects $G$.
- **strongly connected digraph:** a directed graph with a directed path between every ordered pair of vertices.
- **weakly connected digraph:** a directed graph whose underlying undirected graph is connected.
- **strongly connected component:** a maximal strongly connected subgraph of a directed graph.

---

### Section 10.5: Euler and Hamilton Paths
*See [[10.5 Euler and Hamilton Paths]]*

- **Euler path:** a simple path containing every edge of a graph exactly once.
- **Euler circuit:** a simple circuit containing every edge of a graph exactly once.
- **Hamilton path:** a simple path passing through each vertex of a graph exactly once.
- **Hamilton circuit:** a simple circuit passing through each vertex of a graph exactly once.
- **Gray code:** a cyclic ordering of $n$-bit strings where adjacent strings differ in exactly one bit (a Hamilton circuit in $Q_n$).

---

### Section 10.6: Shortest-Path Problems
*See [[10.6 Shortest-Path Problems]]*

- **weighted graph:** a graph with numerical weights assigned to each edge.
- **length of a path:** the sum of weights of the edges in that path.
- **shortest-path problem:** finding a path between two specified vertices with minimal total edge weight.
- **Dijkstra's algorithm:** an iterative greedy algorithm finding shortest path lengths from a source vertex $a$ to target vertices in a weighted graph.
- **traveling salesperson problem (TSP):** finding a Hamilton circuit of minimum total weight in a complete weighted graph.

---

### Section 10.7: Planar Graphs
*See [[10.7 Planar Graphs]]*

- **planar graph:** a graph that can be drawn in the plane without edges crossing.
- **planar representation:** a crossing-free drawing of a planar graph in the plane.
- **region:** a contiguous two-dimensional section of the plane bounded by edges of a planar representation, including the unbounded exterior region.
- **degree of a region $\deg(R)$:** the number of edges on the boundary of region $R$.
- **elementary subdivision:** removing an edge $\{u, v\}$ and inserting a new vertex $w$ with edges $\{u, w\}$ and $\{w, v\}$.
- **homeomorphic graphs:** graphs that can be obtained from the same graph by sequences of elementary subdivisions.

---

### Section 10.8: Graph Coloring
*See [[10.8 Graph Coloring]]*

- **dual graph of a map:** the planar graph whose vertices represent regions of a map and whose edges represent shared borders.
- **graph coloring:** an assignment of colors to vertices such that no two adjacent vertices receive the same color.
- **chromatic number $\chi(G)$:** the least number of colors needed to color graph $G$.
- **The Four Color Theorem:** every planar graph has $\chi(G) \le 4$.

## Key Results

### Fundamental Graph Properties
- **The Handshaking Theorem:** For any undirected graph $G = (V, E)$ with $e$ edges:
  $$2e = \sum_{v \in V} \deg(v)$$
- **Even Number of Odd Vertices:** An undirected graph always has an even number of vertices of odd degree.
- **Directed Handshaking:** For any directed graph $G = (V, E)$:
  $$\sum_{v \in V} \deg^-(v) = \sum_{v \in V} \deg^+(v) = |E|$$
- **Bipartite Characterization:** A graph is bipartite if and only if it contains no simple odd cycles (no cycles of odd length).
- **Hall's Marriage Theorem:** A bipartite graph $G = (V, E)$ with bipartition $(V_1, V_2)$ has a complete matching from $V_1$ to $V_2$ if and only if:
  $$|N(A)| \ge |A| \quad \text{for all } A \subseteq V_1$$

---

### Connectivity Results
- **Paths via Adjacency Matrix Powers:** If $A$ is the adjacency matrix of a graph, the $(i, j)$ entry of $A^r$ is the exact number of paths of length $r$ from $v_i$ to $v_j$.
- **Connectivity Inequality:** For any connected graph $G$:
  $$\kappa(G) \le \lambda(G) \le \min_{v \in V} \deg(v)$$

---

### Euler and Hamilton Paths
- **Euler Circuit Theorem (Theorem 10.5.1):** A connected multigraph with at least two vertices has an Euler circuit if and only if every vertex has an even degree.
- **Euler Path Theorem (Theorem 10.5.2):** A connected multigraph has an Euler path (and no Euler circuit) if and only if it has exactly two vertices of odd degree.
- **Dirac's Theorem (Theorem 10.5.3):** If $G$ is a simple graph with $n \ge 3$ vertices such that $\deg(v) \ge n/2$ for all $v \in V$, then $G$ has a Hamilton circuit.
- **Ore's Theorem (Theorem 10.5.4):** If $G$ is a simple graph with $n \ge 3$ vertices such that $\deg(u) + \deg(v) \ge n$ for every pair of nonadjacent vertices $u$ and $v$, then $G$ has a Hamilton circuit.

---

### Shortest Paths and Complexity
- **Correctness of Dijkstra's Algorithm (Theorem 10.6.1):** Dijkstra's algorithm finds the shortest path length from a source vertex $a$ to all reachable vertices in a weighted graph with positive weights.
- **Complexity of Dijkstra's Algorithm (Theorem 10.6.2):** Dijkstra's algorithm executes in $O(n^2)$ time with standard array labeling (and $O(m + n \log n)$ with min-heaps).
- **TSP Search Space:** An exhaustive search for TSP among $n$ vertices requires examining $\frac{(n-1)!}{2}$ circuits, making it computationally intractable for large $n$ (NP-complete).

---

### Planarity and Graph Colorings
- **Euler's Formula (Theorem 10.7.1):** For any connected planar simple graph with $e$ edges, $v$ vertices, and $r$ regions:
  $$r = e - v + 2$$
- **Planarity Corollaries:**
  - If $v \ge 3$, then $e \le 3v - 6$.
  - Every connected planar simple graph has a vertex of degree at most $5$ ($\deg(v) \le 5$).
  - If $v \ge 3$ and $G$ has no cycles of length $3$, then $e \le 2v - 4$.
- **Kuratowski's Theorem (Theorem 10.7.2):** A graph is nonplanar if and only if it contains a subgraph homeomorphic to $K_{3,3}$ or $K_5$.
- **The Four Color Theorem (Theorem 10.8.1):** The chromatic number of any planar graph satisfies:
  $$\chi(G) \le 4$$
- **Chromatic Numbers of Standard Families:**
  - Complete graphs: $\chi(K_n) = n$
  - Complete bipartite graphs: $\chi(K_{m,n}) = 2$ ($m, n \ge 1$)
  - Cycles: $\chi(C_n) = 2$ if $n$ is even; $\chi(C_n) = 3$ if $n$ is odd ($n \ge 3$)
