# Chapter 3 — Key Terms and Results

## Key Terms

### Section 3.1: Algorithms
*See [[03.1 Algorithms]]*

- **algorithm**: a finite sequence of precise instructions for performing a computation or solving a problem
- **searching algorithm**: the problem of locating an element in a list
- **linear search algorithm**: a procedure for searching a list element by element
- **binary search algorithm**: a procedure for searching an ordered list by successively splitting the list in half
- **sorting**: the reordering of the elements of a list into prescribed order
- **bubble sort**: a sorting algorithm that puts a list into increasing order by successively comparing adjacent elements and interchanging them if they are in the wrong order
- **insertion sort**: a sorting algorithm that at the $j$th step inserts the $j$th element into the correct position in the list, when the first $j - 1$ elements of the list are already sorted
- **greedy algorithm**: an algorithm that makes the best choice at each step according to some specified condition
- **halting problem**: the problem of determining whether a computer program will eventually stop when run with a given input
- **solvable problem**: a problem that can be solved by an algorithm
- **unsolvable problem**: a problem that cannot be solved by an algorithm

### Section 3.2: The Growth of Functions
*See [[03.2 The Growth of Functions]]*

- **$f(x)$ is $O(g(x))$ (big-$O$ notation)**: the property that $|f(x)| \le C|g(x)|$ for all $x > k$ for some constants $C$ and $k$
- **witness to the relationship $f(x)$ is $O(g(x))$**: a pair of constants $C$ and $k$ such that $|f(x)| \le C|g(x)|$ whenever $x > k$
- **$f(x)$ is $\Omega(g(x))$ (big-Omega notation)**: the property that $|f(x)| \ge C|g(x)|$ for all $x > k$ for some positive constants $C$ and $k$
- **$f(x)$ is $\Theta(g(x))$ (big-Theta notation)**: the property that $f(x)$ is both $O(g(x))$ and $\Omega(g(x))$
- **same order**: two functions $f(x)$ and $g(x)$ that satisfy both $f(x)$ is $O(g(x))$ and $g(x)$ is $O(f(x))$, or equivalently $f(x)$ is $\Theta(g(x))$

### Section 3.3: Complexity of Algorithms
*See [[03.3 Complexity of Algorithms]]*

- **time complexity**: the amount of time required for an algorithm to solve a problem (measured in terms of operations)
- **space complexity**: the amount of space in computer memory required for an algorithm to solve a problem
- **worst-case time complexity**: the greatest amount of time required for an algorithm to solve a problem of a given size
- **average-case time complexity**: the average amount of time required for an algorithm to solve a problem of a given size
- **best-case time complexity**: the minimum amount of time required for an algorithm to solve a problem of a given size
- **algorithmic paradigm**: a general approach for constructing algorithms based on a particular concept
- **brute force**: the algorithmic paradigm based on constructing algorithms for solving problems in a naive manner from the statement of the problem and definitions
- **tractable problem**: a problem for which there is a worst-case polynomial-time algorithm that solves it
- **intractable problem**: a problem for which no worst-case polynomial-time algorithm exists for solving it
- **class P**: the class of problems that can be solved in polynomial worst-case time
- **class NP**: the class of problems for which a solution can be checked in polynomial time
- **NP-complete problem**: a problem in NP with the property that if any of these problems can be solved by a polynomial worst-case time algorithm, then all problems in the class NP can be solved by polynomial worst-case time algorithms

## Key Results

The central results, algorithm complexities, and reference rules established in Chapter 3:

1. **Algorithm Complexities** (Sections 3.1 & 3.3):
   - **Linear search**: Uses $\Theta(n)$ comparisons in the worst case (and on average).
   - **Binary search**: Uses $\Theta(\log n)$ comparisons in the worst case.
   - **Bubble sort**: Uses $\frac{n(n - 1)}{2}$ comparisons; worst-case time complexity is $\Theta(n^2)$.
   - **Insertion sort**: Uses $\frac{n(n + 1)}{2} - 1$ comparisons in the worst case; worst-case time complexity is $\Theta(n^2)$.
   - **Optimal comparison sorting**: Sorting $n$ elements can be performed in $O(n \log n)$ time.
   - **Matrix multiplication**: Standard algorithm for two $n \times n$ matrices uses $n^3$ multiplications and $n^2(n - 1)$ additions, giving $O(n^3)$ operations.
   - **Boolean product of zero–one matrices**: Computing $A \odot B$ for two $n \times n$ matrices uses $2n^3$ bit operations.

2. **Properties of Big-$O$, Big-$\Omega$, and Big-$\Theta$** (Section 3.2):
   - **Factorial growth**: $\log n!$ is $O(n \log n)$.
   - **Sum Rule**: If $f_1(x)$ is $O(g_1(x))$ and $f_2(x)$ is $O(g_2(x))$, then $(f_1 + f_2)(x)$ is $O(\max(|g_1(x)|, |g_2(x)|))$.
   - **Product Rule**: If $f_1(x)$ is $O(g_1(x))$ and $f_2(x)$ is $O(g_2(x))$, then $(f_1 f_2)(x)$ is $O(g_1(x) g_2(x))$.
   - **Leading Term of Polynomials**: If $f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$ with $a_n \neq 0$, then $f(x)$ is of order $x^n$, so $f(x)$ is $\Theta(x^n)$, $O(x^n)$, and $\Omega(x^n)$.
   - **Hierarchy of Growth**:
     $$1 \prec \log n \prec n \prec n \log n \prec n^2 \prec 2^n \prec n!$$

3. **Common Complexity Terminology** (Section 3.3):
   - $\Theta(1)$: Constant complexity
   - $\Theta(\log n)$: Logarithmic complexity
   - $\Theta(n)$: Linear complexity
   - $\Theta(n \log n)$: Linearithmic complexity
   - $\Theta(n^b)$: Polynomial complexity
   - $\Theta(b^n)$ ($b > 1$): Exponential complexity
   - $\Theta(n!)$: Factorial complexity

4. **The Halting Problem and Unsolvability** (Section 3.1):
   - There does not exist a computer program that can determine whether an arbitrary program $P$ with input $I$ eventually halts. The halting problem is unsolvable.
