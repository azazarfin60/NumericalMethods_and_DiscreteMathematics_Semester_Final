# Chapter 5 — Key Terms and Results

## Key Terms

### Section 5.1: Mathematical Induction
*See [[05.1 Mathematical Induction]]*

- **sequence:** a function with domain that is a subset of the set of integers.
- **geometric progression:** a sequence of the form $a, ar, ar^2, \dots$, where $a$ and $r$ are real numbers.
- **arithmetic progression:** a sequence of the form $a, a + d, a + 2d, \dots$, where $a$ and $d$ are real numbers.
- **the principle of mathematical induction:** the statement $\forall n\, P(n)$ is true if $P(1)$ is true and $\forall k\, [P(k) \to P(k + 1)]$ is true.
- **basis step:** the proof of $P(1)$ in a proof by mathematical induction of $\forall n\, P(n)$.
- **inductive step:** the proof of $P(k) \to P(k + 1)$ for all positive integers $k$ in a proof by mathematical induction of $\forall n\, P(n)$.
- **inductive hypothesis:** the assumption that $P(k)$ is true in the inductive step.

---

### Section 5.2: Strong Induction and Well-Ordering
*See [[05.2 Strong Induction and Well-Ordering]]*

- **strong induction:** the statement $\forall n\, P(n)$ is true if $P(1)$ is true and $\forall k\, [(P(1) \land \dots \land P(k)) \to P(k + 1)]$ is true.
- **well-ordering property:** every nonempty set of nonnegative integers has a least element.

---

### Section 5.3: Recursive Definitions and Structural Induction
*See [[05.3 Recursive Definitions and Structural Induction]]*

- **recursive definition of a function:** a definition of a function that specifies an initial set of values and a rule for obtaining values of this function at integers from its values at smaller integers.
- **recursive definition of a set:** a definition of a set that specifies an initial set of elements in the set and a rule for obtaining other elements from those in the set.
- **structural induction:** a technique for proving results about recursively defined sets.
- **rooted tree:** a set of vertices containing a distinguished vertex called the root, and edges connecting vertices.
- **extended binary tree:** a tree consisting of either the empty set or a root together with a left subtree and a right subtree.
- **full binary tree:** a tree consisting of either a single vertex or a root together with a left and right full binary tree.
- **height:** the maximum depth of any vertex in a rooted tree (for a full binary tree $T$, $h(T) = 0$ if $T$ consists of a single root, and $h(T) = 1 + \max(h(T_1), h(T_2))$).

---

### Section 5.4: Recursive Algorithms
*See [[05.4 Recursive Algorithms]]*

- **recursive algorithm:** an algorithm that proceeds by reducing a problem to the same problem with smaller input.
- **merge sort:** a sorting algorithm that sorts a list by splitting it in two, sorting each of the two resulting lists, and merging the results into a sorted list.
- **iteration:** a procedure based on the repeated use of operations in a loop.

---

### Section 5.5: Program Correctness
*See [[05.5 Program Correctness]]*

- **program correctness:** verification that a procedure always produces the correct result.
- **partial correctness:** the property that a program yields the correct output if it terminates.
- **initial assertion:** the statement specifying the properties of the input values of a program.
- **final assertion:** the statement specifying the properties the output values should have if the program worked correctly.
- **Hoare triple:** the notation $p\{S\}q$, stating that if assertion $p$ is true before program segment $S$ is executed, then assertion $q$ is true after execution if $S$ terminates.
- **loop invariant:** a property that remains true during every traversal of a loop.

---

## Key Results

- **The Principle of Mathematical Induction:** To prove that $P(n)$ is true for all positive integers $n$, where $P(n)$ is a propositional function, we complete two steps:
  1. *Basis Step:* Verify that $P(1)$ is true.
  2. *Inductive Step:* Show that the conditional statement $P(k) \to P(k + 1)$ is true for all positive integers $k$.
  In symbols:
  $$[P(1) \land \forall k\, (P(k) \to P(k + 1))] \to \forall n\, P(n)$$

- **The Principle of Strong Induction:** To prove that $P(n)$ is true for all positive integers $n$, where $P(n)$ is a propositional function, we complete two steps:
  1. *Basis Step:* Verify that the proposition $P(1)$ is true.
  2. *Inductive Step:* Show that the conditional statement $[P(1) \land P(2) \land \dots \land P(k)] \to P(k + 1)$ is true for all positive integers $k$.
  In symbols:
  $$[P(1) \land \forall k\, ((P(1) \land P(2) \land \dots \land P(k)) \to P(k + 1))] \to \forall n\, P(n)$$

- **The Well-Ordering Property:** Every nonempty set of nonnegative integers has a least element.

- **Equivalence of Induction Principles:** Mathematical induction, strong induction, and well-ordering are all logically equivalent proof techniques when applied to the set of positive integers.

- **Lamé's Theorem:** Let $a$ and $b$ be positive integers with $a \geq b$. Then the number of divisions used by the Euclidean algorithm to find $\gcd(a, b)$ is less than or equal to 5 times the number of decimal digits in $b$.

- **Full Binary Tree Vertex Bound:** If $T$ is a full binary tree of height $h(T)$ with $n(T)$ vertices, then:
  $$n(T) \leq 2^{h(T) + 1} - 1$$

- **Complexity of Merge Sort:** The merge sort algorithm sorts a list of $n$ elements using $O(n \log n)$ comparisons.

- **Rules of Inference for Program Correctness (Hoare Logic):**
  - **Composition Rule:**
    $$\frac{p\{S_1\}q, \quad q\{S_2\}r}{p\{S_1; S_2\}r}$$
  - **Conditional Rule (If-Then):**
    $$\frac{(p \land \text{condition})\{S\}q, \quad (p \land \neg\text{condition}) \to q}{p\{\mathbf{if}\ \text{condition}\ \mathbf{then}\ S\}q}$$
  - **Conditional Rule (If-Then-Else):**
    $$\frac{(p \land \text{condition})\{S_1\}q, \quad (p \land \neg\text{condition})\{S_2\}q}{p\{\mathbf{if}\ \text{condition}\ \mathbf{then}\ S_1\ \mathbf{else}\ S_2\}q}$$
  - **While Loop Rule (Loop Invariant):**
    $$\frac{(p \land \text{condition})\{S\}p}{p\{\mathbf{while}\ \text{condition}\ S\}(p \land \neg\text{condition})}$$
