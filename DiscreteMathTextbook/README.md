# Discrete Mathematics — Textbook (Rosen)

Digitized sections from *Discrete Mathematics and Its Applications* by Kenneth H. Rosen, covering all chapters relevant to the ECE 2213 syllabus.

## Chapters

| Directory | Syllabus topics covered |
| :-- | :-- |
| `Chapter 01 - The Foundations - Logic and Proofs` | Propositional logic, predicates, quantifiers, rules of inference, proof techniques |
| `Chapter 02 - Basic Structures - Sets, Functions, Sequences, Sums, and Matrices` | Set operations, algebraic properties, power set theorem |
| `Chapter 03 - Algorithms` | Algorithm complexity (off-syllabus but examined in 2022–2024) |
| `Chapter 04 - Number Theory and Cryptography` | Modular arithmetic, GCD/LCM, primes, congruence, CRT |
| `Chapter 05 - Induction and Recursion` | Mathematical induction, proof by contradiction |
| `Chapter 06 - Counting` | Counting techniques, pigeonhole principle, permutation, combination, binomial theorem |
| `Chapter 09 - Relations` | Binary relations, partial ordering, equivalence relations |
| `Chapter 10 - Graphs` | Graph theory basics (off-syllabus, included for completeness) |

Each chapter directory contains section-level `.md` files, a summary file, and a `diagrams/` folder with cropped figures and their `.meta.json` sidecars.

## How these files are used

They are **read-only reference material**. When an answer requires a definition, theorem statement, or derivation, the textbook is the authority. Class notes supplement with instructor emphasis. No text is copied verbatim into answer files.
