## Exercises

**11.1** Explain the difference between a function and a functional. Prove that
(a) $\delta(dx) = d(\delta x)$.
(b) $\delta \int f(x)\,dx = \int \delta f(x)\,dx$.

**11.2** Establish the Euler–Lagrange equation
$$\frac{\partial f}{\partial y} - \frac{d}{dx}\left(\frac{\partial f}{\partial y'}\right) = 0,$$
for a functional defined by
$$I(y) = \int_a^b f(x, y, y')\,dx.$$

Obtain functionals for the following boundary value problems (Problems 11.3–11.8):

**11.3**
$$\frac{d^2y}{dx^2} = g(x), \quad y(0) = y(1) = 0.$$

**11.4**
$$\frac{d^2y}{dx^2} + ky = x^3, \quad y(a) = 0, \quad \left[\frac{dy}{dx}\right]_{x=b} = 1.$$

**11.5**
$$x^2 \frac{d^2y}{dx^2} + 2x \frac{dy}{dx} = g(x), \quad y(0) = y(1) = 0.$$

**11.6**
$$\frac{d^2y}{dx^2} + p(x)y + q(x) = 0, \quad y(a) = y(b) = 0.$$

**11.7**
$$\frac{d^4y}{dx^4} + ky = f(x), \quad 0 < x < 1,$$
$$y = \frac{d^2y}{dx^2} = 0 \text{ at } x = 0 \text{ and } x = 1.$$

Solve the following boundary value problems by Rayleigh–Ritz method (Problems 11.8–11.10):

**11.8**
$$\frac{d^2y}{dx^2} + y = x^2, \quad y(0) = y(1) = 0.$$

**11.9**
$$\frac{d^2y}{dx^2} + 2x = 0, \quad y(0) = y(1) = 0.$$

**11.10**
$$\frac{d^2y}{dx^2} - 64y + 10 = 0, \quad y(0) = y(1) = 0.$$

## Answers to Exercises

**11.3**
$$I(v) = \int_0^1 \left[ \frac{1}{2}\left(\frac{dv}{dx}\right)^2 + gv \right] dx$$

**11.4**
$$I(v) = \int_a^b \left[ \left(\frac{dv}{dx}\right)^2 - kv^2 + 2vx^3 \right] dx - v(b)$$

**11.5**
$$I(v) = \int_a^b v \left[ 2g - \frac{d}{dx}\left(x^2 \frac{dv}{dx}\right) \right] dx$$

**11.6**
$$I(v) = \int_a^b \left[ \left(\frac{dv}{dx}\right)^2 - pv^2 - 2qv \right] dx$$

**11.7**
$$I(v) = \int_0^1 \left[ \left(\frac{d^2v}{dx^2}\right)^2 + kv^2 - 2fv \right] dx$$

**11.8**
$$I(v) = \int_0^1 \left[ \left(\frac{dv}{dx}\right)^2 - v^2 + 2vx^2 \right] dx;$$
$$y(x) \approx v(x) = -\frac{10}{121}x(1 - x) - \frac{7}{41}x^2(1 - x)$$

**11.9**
$$I(v) = \int_0^1 \left[ \left(\frac{dv}{dx}\right)^2 - 4vx \right] dx; \quad y(x) \approx v(x) = \frac{1}{3}(x - x^3).$$

**11.10**
$$v(x) = \frac{25}{37}x(1 - x)$$

**11.11**
$$v(x) = -\frac{10}{123}x(1 - x) - \frac{7}{41}x^2(1 - x)$$

**11.12**
$$v(x) = \frac{25}{37}x(1 - x)$$
