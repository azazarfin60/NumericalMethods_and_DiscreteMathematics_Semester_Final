# Numerical Methods — Textbook (Jain, Iyengar & Jain)

Digitized sections from *Numerical Methods for Scientific and Engineering Computation* by M.K. Jain, S.R.K. Iyengar & R.K. Jain, covering all chapters relevant to the ECE 2213 syllabus.

## Chapters

| Directory | Syllabus topics covered |
| :-- | :-- |
| `Chapter 01 - Errors in Numerical Calculations` | Error types, round-off, truncation, significant digits |
| `Chapter 02 - Solution of Algebraic and Transcendental Equations` | Bisection, false position, Newton-Raphson, secant method |
| `Chapter 03 - Interpolation` | Finite differences, Newton's forward/backward, Lagrange, divided differences, central difference formulas |
| `Chapter 04 - Least Squares and Fourier Transforms` | Least squares regression, curve fitting |
| `Chapter 05 - Spline Functions` | Spline interpolation |
| `Chapter 06 - Numerical Differentiation and Integration` | Trapezoidal rule, Simpson's rules, Romberg, numerical differentiation |
| `Chapter 07 - Numerical Linear Algebra` | Gauss elimination, LU decomposition, Jacobi, Gauss-Seidel, relaxation |
| `Chapter 08 - Numerical Solution of Ordinary Differential Equations` | Euler's method, Runge-Kutta, BVP |
| `Chapter 09 - Numerical Solution of Partial Differential Equations` | Laplace equation, Poisson equation, Liebmann's method |
| `Chapter 10 - Numerical Solution of Integral Equations` | Integral equation methods |
| `Chapter 11 - The Finite Element Method` | FEM basics (off-syllabus, included for completeness) |

Each chapter directory contains section-level `.md` files, exercise files, and a `diagrams/` folder with cropped figures and `.meta.json` sidecars.

## How these files are used

They are **read-only reference material**. The textbook is the authority for formulas, derivations, and algorithm descriptions. Answers cite the method but do not copy textbook prose.
